Apple iOS (iPhone & iPad)
Pemasangan di Layar Utama via Safari
1
Buka Link di Browser Safari
Buka peramban resmi Safari di iPhone/iPad Anda, lalu akses link URL NersCalc yang telah diberikan.
🧭
Gunakan Safari (Bukan Chrome iOS)
Fitur PWA iOS hanya didukung penuh via Safari
2
Tekan Tombol "Bagikan" (Share)
Perhatikan bilah bawah peramban Safari. Ketuk tombol Share (ikon persegi dengan tanda panah mengarah ke atas).
Ikon Share Lembar Bawah
Posisinya berada di tengah bawah layar iPhone
3
Pilih "Tambahkan ke Layar Utama"
Gulir ke bawah pada lembar pilihan share hingga menemukan menu "Tambahkan ke Layar Utama" (Add to Home Screen).
Tambahkan ke Layar Utama (+)
Ketuk baris ini untuk membuka dialog instal
4
Konfirmasi & Klik "Tambah"
Nama aplikasi NersCalc akan otomatis terisi. Ketuk tombol "Tambah" (Add) di pojok kanan atas.
✓
Selesai! Ikon Muncul di Home Screen
Buka aplikasi seperti layaknya app App Store
Khusus Pengguna iOS: Jika membuka link melalui WhatsApp atau Telegram, pastikan membuka browser Safari sebenarnya dengan menekan tombol titik tiga lalu pilih "Buka di Browser Eksternal / Open in Safari".

Android Smartphone
Pemasangan via Google Chrome (Samsung, Xiaomi, Oppo, Vivo, Poco, dll.)
1
Buka Link di Google Chrome
Buka tautan NersCalc di browser Google Chrome pada smartphone Android Anda.
🌐
Banner Otomatis di Bawah Layar
Sering kali muncul tombol "Pasang NersCalc"
2
Metode Menu Titik Tiga (⋮)
Jika banner pop-up tidak muncul otomatis, tekan ikon Menu Titik Tiga (⋮) di pojok kanan atas browser Chrome.
⋮
Menu Opsi Google Chrome
Pojok kanan atas di samping bilah URL
3
Pilih "Pasang Aplikasi"
Pilih menu "Pasang aplikasi" atau "Tambahkan ke Layar Utama" (Install app / Add to Home screen).
Menu "Pasang Aplikasi"
Sistem Android akan menyiapkan paket PWA
4
Ketuk Tombol "Instal"
Kotak dialog konfirmasi akan muncul. Ketuk "Instal". Dalam beberapa detik, NersCalc telah terpasang di App Drawer dan Layar Utama!
✓
Terpasang Sepenuhnya
Bisa dibuka dari menu utama tanpa membuka Chrome lagi
Windows PC / Laptop / macOS
Pemasangan Desktop App (Chrome / Microsoft Edge)
1
Klik Ikon Instal di Bilah Alamat (URL Bar)
Saat link NersCalc dibuka di Google Chrome atau Microsoft Edge PC, perhatikan di ujung paling kanan bilah alamat (URL). Terdapat ikon komputer kecil dengan panah ke bawah atau simbol (+).
🖥️
Ikon "Pasang / Install NersCalc"
Tepat di samping ikon bookmark bintang di bar URL
2
Klik "Instal" & Jalankan Sebagai App Mandiri
Klik tombol "Instal". NersCalc akan langsung terbuka dalam jendela desktop mandiri tanpa tab browser. Shortcut otomatis dibuat di Desktop & Start Menu.
🚀
Jendela Bersih & Super Cepat
Siap dipakai di meja perawat / posko jaga
