## ⚡ Ringkasan Cepat Pemasangan

### 1. 🍏 Apple iOS (iPhone & iPad via Safari)
1. Buka tautan / link NersCalc di peramban **Safari**.
2. Ketuk ikon **Bagikan (Share)** yang berada di bilah bawah layar (ikon kotak panah atas).
3. Gulir ke bawah lalu pilih menu **"Tambahkan ke Layar Utama" (Add to Home Screen)**.
4. Ketuk **"Tambah" (Add)** di sudut kanan atas.
5. Ikon NersCalc langsung tampil di layar depan iPhone layaknya aplikasi resmi dari App Store!

### 2. 🤖 Android (Samsung, Xiaomi, Oppo, Vivo, Poco, dll. via Google Chrome)
1. Buka tautan / link NersCalc di **Google Chrome**.
2. Jika banner muncul di bawah layar, klik tombol **"Pasang Aplikasi" / "Tambahkan ke Layar Utama"**.
3. Jika banner tidak muncul, ketuk ikon **Menu Titik Tiga (⋮)** di kanan atas Chrome.
4. Pilih **"Pasang aplikasi"** atau **"Tambahkan ke Layar Utama"**.
5. Tekan **"Instal"** pada jendela konfirmasi. Aplikasi siap digunakan 100% offline!

### 3. 💻 Komputer PC / Laptop (Windows & macOS via Chrome atau Edge)
1. Buka link NersCalc di browser Chrome / Microsoft Edge.
2. Perhatikan sisi kanan **Bilah Alamat (URL Bar)**, klik ikon **"Instal NersCalc"** (ikon komputer / panah).
3. Klik tombol **"Instal"**.
4. NersCalc akan berjalan sebagai aplikasi desktop mandiri tanpa address bar, lengkap dengan shortcut desktop.
